# Отменённые решения (архив)

Свод отменённых и перекалиброванных решений, собранный 13.06.2026, чтобы сохранить контекст «почему раньше думали иначе», не засоряя основные доки. Актуальный канон — «Решения и видение».

## Вертикаль и ICP (разворот 16.08.2026)
- Отменено: «общепит — первая дверь продаж, вход через ≥6/10 болей + ≥3 пилота». Стало: основной вход — персональные автоматизации (личный агент: почта, календарь, таблицы, мессенджер); общепит понижен до вторичного сценария. Причина: инбаунд с корп-сайта и дог-фуд на себе дают обратную связь быстрее, чем холодный обход заведений; ICP сместился на владельца малого бизнеса/самостоятельного специалиста. Материал по общепиту (6 сценариев, policy-матрица, eval-датасет, персона «Марина») сохранён как рабочий тестовый набор и будущий шаблон.
- Отменено: «MVP-1 = первый шаблон "администратор общепита", 6 сценариев». Стало: MVP-1 = сквозная персональная автоматизация (входящее → policy → approval → действие в Google Calendar/Sheets → аудит).
- Отменено: «финальная вертикаль после 15–20 холодных интервью». Стало: вертикаль расширения определяется инбаундом с корп-сайта.
- Снята цена 25/39 тыс ₽/мес как канон (считалась под гостевой поток заведения). Новая рамка — гибрид с единицей agent run, точная цена под новый ICP не определена.
- Отменён аккаунт на корп-сайте (16.08): не заводим отдельную авторизацию ради кредитов; связка по контакту + ручная привязка модератором.

## Цена и тарифы
- Отменён тариф «Старт 19 900 ₽». Стало: Старт 25 000, Бизнес 39 000. Причина: якорь оффера «пилот 15k вместо 25k» требует регулярной цены 25k; держим премиум-позиционирование.
- Уточнена пост-пилотная вилка «20–25 тыс» до конкретной лестницы: Пилот 15 → Старт 25 → Бизнес 39.
- Отменён эксперимент «5 тыс ₽ + оплата за результат» (нижний сегмент). Причина: бьёт по премиум-позиционированию; вход — бесплатная неделя-стажёр, а не дешёвый тариф. Прайсинг «за результат ₽/бронь» остаётся возможной P1-моделью, но не как дешёвый сегмент.

## Юнит-экономика
- Пересчитано: COGS 2 700 ₽ / маржа 86% при чеке 20 тыс → COGS ≈ 4 800 ₽ / маржа ~80% при чеке 25 тыс (с УСН и эквайрингом; старый расчёт их не включал).

## Финмодель
- Оптимистичная воронка (10,5%) понижена до статуса «потолка». Канон — честная v2 (4,8%), т.к. 10,5% — уровень опытного фултайм-сейлза, а не part-time джуна.
- Kill-критерий «мес 12: MRR ≥ 100 тыс» снижен до ≥ 60 тыс (+ удержание клиента 6 мес + канал с CAC), т.к. честная база даёт ~76 тыс к м24, а старый критерий проваливался гарантированно.

## Позиционирование и вертикали
- Переформулировано: «вторая вертикаль = консалтинг» → основной путь расширения — класс SMB с бронями (онлайн-школы, глэмпинги, мини-отели); консалтинг — параллельный разведочный трек. Общепит — дверь продаж, не идентичность продукта.
- Медицина/юр переведены из «антиперсон (не берём)» в «перспективу развития» (152-ФЗ + дорогая ошибка = сильная боль и высокий чек, берём после де-рискинга юрконструкции).

## Канал владельца
- Отменено: «вход только по email, Telegram — P1». Стало: Telegram как gateway с MVP-1 (один аккаунт, несколько каналов входа, TG-вход привязывает tg_chat_id и даёт инлайн-решения ✅/✏️/❌).

## Продукт / scope
- Авто-правила автономности перенесены из MVP-1 в MVP-2 (в MVP-1 только UI-предложение «разрешить автоматически?», без применения).
- Убран Google Sheets как «бэкенд для бедных»: одна каноничная схема в Postgres, вариативность клиента — в jsonb-настройках и md-знаниях, внешние системы за портами.
- Уточнено: «реальная книга броней не входит» → своя книга в Postgres есть (заявка + approval + FSM с авто-переходами по времени); нет внешней/касса-подтверждённой (iiko — MVP-2).
- «10 экранов» уточнено до 19 (15 MVP-1 + 4 MVP-2) — устаревшая цифра в Обзоре.

## Дизайн
- Уточнено: «геймификация (стрики/ачивки) — не делаем» → запрещена только поверхностная для владельца; глубокая (прогрессия доверия, присвоенный прогресс, разблокировка автономии) используется осознанно.
