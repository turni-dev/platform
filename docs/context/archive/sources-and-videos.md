# Источники и видео (архив)

Ключевая мысль, вынесенная из просмотренных видео: продавать нужно образ жизни, а не сотрудника — не «купи ИИ-сотрудника», а «вот как ты будешь жить, если создашь агентов, которые делают больше других».

Список видео-источников:
1. AI Employees: The Biggest Opportunity of 2026 (Almost Nobody's Doing It) — Luuk Alleman. Про бизнес-возможность «ИИ-сотрудников» в 2026, источник идеи «продавать образ жизни».
2. LLM Observability, Evaluation, Experimentation Platform — Dat Ngo (Arize), конференция AI Engineer. Про observability и evals для LLM — относится к аудиту/наблюдаемости control plane.
3. Hermes + Paperclip Just Changed AI Agents Forever — Julian Goldie SEO. Про возможности Hermes как agent runtime.
4. How to Build a Multi-Agent Workflow for LLM Wikis in Hermes Kanban — Tonbi's AI Garage. Пример мультиагентных recurring-сценариев на Hermes.
