# Ресёрч: Google NotebookLM — что взяли

NotebookLM — эталон source-grounded RAG с цитатами: отвечает только из загруженных источников,
inline-цитаты кликабельны (клик → точный фрагмент источника), закрытый корпус резко снижает
галлюцинации. Изучен как ориентир для узких мест: онбординг (загрузка источников) и faithfulness
(«не выдумывай», особенно аллергены).

## Вывод

Взяты три паттерна: (1) онбординг через загрузку источников (сайт/меню PDF → авто-база знаний +
аллергены), (2) кликабельные inline-цитаты в ответах, (3) авто-артефакты из источников (FAQ, таблицы,
карта знаний). Сам продукт — Google-облако (данные вне РФ, неприемлемо по 152-ФЗ) → взят паттерн, не
продукт; grounded-RAG строится на своей инфре (pgvector + faithfulness-eval).

## Что взяли

1. **Онбординг через загрузку источников** — вместо ручного ввода меню/FAQ владельцем: загрузить сайт
   заведения + меню (PDF/фото) → авто-извлечение в структурированную базу знаний + поля аллергенов
   (Data Tables). Ускоряет самый хрупкий этап онбординга и наполняет базу с первого дня.
2. **Кликабельные inline-цитаты** — усиление существующего ExplainWhy («причина+источник») до уровня
   «клик по ответу → точный фрагмент карточки знаний», особенно критично для аллергенов (ответ
   ссылается на точное поле меню, владелец проверяет в клик). Прямая митигация OWASP LLM09
   (faithfulness).
3. **Авто-артефакты из источников**: авто-FAQ из сайта/меню (сидинг базы, анти-cold-start),
   авто-саммари загруженного («вот что я понял»), mind map базы знаний (визуализация «что знает
   агент»), Data Tables (структурный экстракт меню с колонкой аллергенов).
4. **Позиционирование «закрытый корпус»** — «агент отвечает только из ваших данных, не выдумывает из
   интернета» — сильный месседж доверия, совпадает с принципом «ответ только из базы, иначе уточню».
5. **Notebook = scoped knowledge** — подтвердил модель изоляции знаний per-tenant/agent.

## Что не взяли

NotebookLM — research-тул для чтения человеком (человек грузит, спрашивает); продукт — автономный
ответ гостю + approval, поэтому берётся grounding/цитаты/ingest, а не сама метафора «ноутбука». Не
взяты Audio/Video Overview, квизы, флешкарты — не ядро для общепита (аудио-дайджест недельного отчёта
рассматривался как нишевая опция, не приоритет). Google-облако не используется из-за 152-ФЗ.
