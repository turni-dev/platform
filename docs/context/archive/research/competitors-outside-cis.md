# Ресёрч: конкуренты вне СНГ — что взяли

Изучены зарубежные игроки: общепит/hospitality (voice/phone-first) и CX-агенты с контролем
(Decagon/Sierra), а также их стратегии дистрибуции и ценообразования.

## Два главных вывода

1. Зарубежный общепит почти весь voice/phone-first (их канал — звонки); собственная модель —
   messaging-first, это СНГ-дифференциация и подтверждение, что голос — главный gap на будущее.
2. Топовые CX-агенты Decagon/Sierra реализуют ровно тот же контроль-слой (политики на естественном
   языке → исполняемые правила + guardrails + supervisory-агент + аудит) — позиционирование
   «Decagon/Sierra для SMB по SMB-цене» подтверждено как верное направление.

## CX-агенты с контролем — Decagon/Sierra

- **Decagon**: AOP (Agent Operating Procedures) — логика на естественном языке → компиляция в
  исполняемые воркфлоу с guardrails; 4 слоя защиты (system-level + supervisory + adversarial testing +
  automated behavioral QM); Watchtower — real-time QA. Взято: фрейминг «4 слоя защиты» и идея
  real-time QA (ночной ретро-eval + алерты).
- **Sierra**: supervisory-агент enforce-ит политики (второй агент — «полицейский»); детерминированные
  guardrails для критичной логики; PII auto-masking; фильтры off-limits-тем. Взято: supervisory-агент
  для риск-критичных ответов; детерминированные guardrails (level-0 + locked); PII-маскинг.
- Оба фокусируются на бизнес-исходах (resolution, CSAT, конверсия), не containment/vanity-метриках —
  валидирует фокус на resolution + отчёт деньгами.

## Шорт-лист фич (по приоритету)

1. Альт-слот при «занято» (Slang) — дёшево, MVP-1/2.
2. Банкет/группа → сбор деталей → пуш владельцу (Newo) — уже в бэклоге, подтверждено нормой индустрии.
3. ROI-отчёт «возвращённая выручка + сэкономленный труд» (Loman) — усиление отчёта конкретикой.
4. 4 слоя защиты + real-time QA (Decagon) — фрейминг policy/eval/audit.
5. Supervisory-агент (Sierra) — для риск-критичных ответов.
6. Проактивное промо спецпредложений (Popmenu) — апселл.
7. Бенчмаркинг «ты vs похожие заведения» (Slang) — будущая аналитика-фича при масштабе.
8. Структурный импорт меню/аллергенов — урок Slang + NotebookLM-ingest.

## Что не копируется

Voice-first как единственный канал (продукт messaging-first для СНГ, голос — отдельный gap MVP-3);
enterprise-сложность Sierra/Decagon (SMB-цена, лёгкое внедрение); глубокая POS-интеграция в MVP-1
(iiko — MVP-2/3).

## Стратегия, модель, дистрибуция

- Рынок виртуальных ресепшен $3,85 млрд (2024) → ~$9 млрд (2033); POS-гиганты (Toast/Square/PAR)
  запускают своих ИИ-агентов — валидирует категорию «AI employee/receptionist», но повторяет угрозу:
  платформа, где уже сидят SMB (у нас iiko/Яндекс/Битрикс24), может встроить ИИ сама — окно закрывается.
- Ценовой ландшафт: человек-ресепшен ≈$3100/мес → ИИ дешевле на 85–95% (главный якорь ценности);
  flat $59–349/мес, per-minute $0,05–0,20, per-resolution (Fin $0,99). Собственный premium-flat 25k
  (~$280) в рынке US-flat защитим за счёт messaging+контроль+отчёт (не voice-only). Функцию
  usage/outcome-прайсинга для снижения риска покупателя выполняет бесплатная неделя + пилот 15k.

### Дистрибуция — главный недооценённый рычаг

US-стартапы набирают рестораны оптом через маркетплейсы POS (Toast/Square/PAR: «интеграция за 60 мин»
+ листинг), а не только фичами. **Решение: аналог для СНГ — iiko/r_keeper маркетплейс, YCLIENTS, Avito,
экосистема Telegram, 2ГИС/Яндекс.** iiko — не только интеграция (MVP-2), а канал дистрибуции;
партнёрство с iiko рассматривается как приоритет, до того как они построят своё решение (двойная роль:
канал и угроза).

### Missed-contact recovery / text-back — высокий приоритет

US-статистика: 62% звонков SMB без ответа, 85% не перезвонят, авто-текст-бэк в 1 мин возвращает 93%
лидов, +$3500/мес. **Решение:** пропущенный звонок заведения → агент мгновенно пишет в TG/SMS — мост к
голос-каналу без постройки голосового агента, самый чистый ROI-нарратив, безопасный «исходящий» (пишем
тому, кто сам звонил). Приоритет поднят на рассмотрение MVP-2 вместо MVP-3 (требует детекции
пропущенного звонка — виртуальный номер/переадресация/телефония).

### Онбординг / time-to-value

«Live за 24ч», «1-клик: скорми меню», «Toast за 60 мин» — TTV признан конкурентной необходимостью,
подтверждает требование к быстрому онбордингу (20-мин чат + ingest источников).

## Итоговый список «прям нужное»

1. Дистрибуция через iiko-маркетплейс/платформы — стратегический канал, партнёриться раньше конкурентов.
2. Missed-call → text-back в TG — дешёвый мост к голосу + сильнейший ROI-хук, приоритет поднят.
3. Outbound-revenue (no-show recovery, win-back, waitlist) — подтверждено как первичный, не вторичный
   драйвер выручки.
4. Быстрый TTV — onboarding-ingest как конкурентная необходимость.
5. White-label/агентский канал — MVP-3 white-label подтверждён как реальный канал (аналог Synthflow).
