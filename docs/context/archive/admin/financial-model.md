# Бизнес-модель: допущения и результаты финмодели

Канон — честная модель v2 (см. team-operating-model.md): реалистичная воронка ~4,8% → к мес 24 ≈ 4 клиента, MRR 76 тыс, итог −160 тыс за 24 мес. Оптимистичный сценарий ниже (+708 тыс) — потолок, не план.

## Маркетинг-модель

Бюджет времени фаундера на маркетинг ~8–9 ч/нед → ~12 единиц контента/мес. Каналы: TG-канал, VC/Habr, чаты, личная сеть (выгорает за 3–4 мес), SEO, партнёры. CAC ≈ 3–12 тыс ₽ временем (без кэша). Воронка: посетитель→лид 3%, подписчик→демо 2%/мес.

## Продажи-модель

Воронка (оптимистичный сценарий, верхняя граница): заявка→демо 70%, демо→платный пилот 30%, пилот→подписка 50%, продление 60%. Сквозная лид→клиент ~10–12%, цикл 8–10 недель. Сделка: старт MRR Пилот 15 → Старт 25 тыс (expansion до Бизнес 39). Churn: 8%/мес первые 3 мес жизни клиента, затем 3%. Потолок соло-продаж: 20–25 активных клиентов; найм CS при 15+ клиентах или MRR ≥350 тыс ₽.

> Примечание из ревизии red team: воронка 70/30/50 и темп лидов (72/год с контента) соответствуют уровню опытного фултайм-сейлза, а не part-time новичка. Для честной оценки — см. более консервативную модель v2 (~4,8% воронка) в team-operating-model.md — она канон.

## Юнит-экономика

COGS на клиента ≈4800 ₽/мес при чеке 25 тыс (LLM ~2000 + инфра ~400 + эквайринг/УСН ~2400) → валовая маржа ≈80%. Cost per resolution ≤3 ₽ против 150–300 ₽ у живого оператора. LTV по марже: churn 5% → ≈400 тыс ₽; 8% → ≈250 тыс; 12% → ≈167 тыс. CAC ≈30–40 тыс ₽ временем → LTV/CAC ≥6, payback ~2 мес. Фикс. расходы растут по стадиям: PoC 9 тыс/мес → MVP 19 тыс → рост 32 тыс → масштаб 76 тыс (без ФОТ).

Чувствительность модели (по убыванию влияния): churn (>15% — LTV/CAC < 3) → объём обращений на клиента (>6000/мес — маржа падает к 40%) → темп лидов (<1 клиента/мес после мес 6 — стагнация).

## Ограничения модели

Месяц найма — единая точка переключения между сценариями. Churn считается блендед (без когортного разделения 8%→3%). Пилотная выручка учитывается как обычный MRR, разовые пилотные платежи не выделены отдельно — модель консервативнее реальности. Все цифры — гипотезы; план — заменить их фактами после первых 10 пилотов.
