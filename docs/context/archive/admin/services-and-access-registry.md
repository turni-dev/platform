# Реестр сервисов и доступов

Инвентарь сервисов/аккаунтов проекта — не хранилище секретов. Пароли, токены, API-ключи не хранятся в этой заметке: они живут в sops/age (`ops/sops/secrets.enc.json`, см. `ops/sops/README.md` в репозитории) или в менеджере паролей. В оригинале фиксируются: сервис, назначение, аккаунт/почта, где искать доступ, владелец, статус (в момент миграции большинство ячеек с конкретными данными не заполнено — оставлены как "заполнить").

[секрет исключён при миграции — см. оригинал в Obsidian: в самой заметке реальных секретов не было, но в исходнике есть плейсхолдеры для учётных данных, которые заполняются по мере заведения доступов]

## Категории сервисов

- **Домены и хостинг:** домен turni.*, VPS/хостинг (compose-деплой: prod API+worker+web, GHCR pull), Timeweb DBaaS (Postgres+pgvector prod).
- **Инфраструктура и CI/CD:** GitHub (репозиторий, CI, CODEOWNERS), GHCR (Docker-образы), deploy-user SSH (приватный ключ вне репо), sops/age (шифрование секретов; приватный age identity хранится в 2 offline-копиях у разных доверенных лиц).
- **LLM и данные:** Yandex AI Studio (YandexGPT + Text Embeddings) — основной LLM/embedding рантайм (RU-first); второй LLM-провайдер как fallback — пока не заведён.
- **Каналы и интеграции:** Telegram BotFather (master-бот, deep-link создание клиентских ботов), YooKassa (оплата подписок, не заведена на момент записи), SMTP-провайдер (email-код входа, уведомления), S3/MinIO (файлы: меню, вложения), n8n (для агентского трека — не заведён, MVP-3+).
- **Маркетинг/контент:** Strapi (self-host, apps/cms) — CMS лендинга/агентского трека.
- **Организационное:** ООО — не оформлено на момент записи; договоры/доли/платежи будут привязаны к юрлицу.

Владелец всех текущих доступов — Максим.

## Правило (жёсткое, security-инвариант проекта)

Ни один реальный пароль/токен/ключ не появляется текстом в этой заметке, в чате с ИИ или в коде — только в sops/age или в password-менеджере. Таблица — карта «что есть и где искать», не хранилище. Ревизия — раз в квартал вместе с проверкой offline-бэкапа age-ключа.
