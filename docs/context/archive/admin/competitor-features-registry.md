# Реестр фич конкурентов (классифицированный)

Что строим и что осознанно не строим. Оценки: P0 = в MVP, P1/P2 = позже, скип = осознанно не делаем. ⭐ = уникальная/неочевидная фича.

## Наша зона P0 (по категориям)

- **Онбординг:** диалоговая генерация инструкции из описания бизнеса (бьёт мусорный выхлоп у Suvvy), live-запуск за 24 часа.
- **Диалог:** склейка сообщений с индикатором «печатает», разбиение длинных ответов, ⭐ Procedures/инструкции естественным языком (AOP-политики на русском).
- **Знания:** база знаний (быстрые ответы + документы), первая линия до LLM как модуль пайплайна (не ручная форма).
- **Контроль (наша главная зона):** перехват сотрудником, ⭐ approval gates на действия, ⭐ эскалация при низкой уверенности с полным контекстом, ⭐ AOP (политика → исполняемые правила, аудитопригодно).
- **Отчётность:** ⭐ отчёт о ROI/business impact в рублях/бронях, алертинг о важных событиях.
- **Каналы:** TG-бот + бронь как действие.
- **Биллинг:** баланс в рублях, низкий вход.

## 5 фич-ловушек (скип, осознанно не делаем)

1. Широкая матрица каналов (30+ как у Suvvy) — общепиту нужны 3–4.
2. Конструктор сценариев/навыков (Wikibot) — перекладывает работу на клиента.
3. Мультиагентный canvas — впечатляет на демо, не нужен пиццерии.
4. Выбор модели/порогов/параметров голоса в UI — когнитивный налог.
5. Рассылки в MVP — риск банов и репутации раньше ценности.

## P1/P2 на бэклог

Готовые персонажи с «характером» (Sintra), self-serve деплой 30–60 мин, Vision для картинок, голос, память предпочтений гостя, таблицы с правами, anti-spam, «какой документ сработал» (объяснимость), auto-confirm броней ночью, POS/резерв-синк, оплата за результат (₽/бронь), наценка реселлера (price_percent).

## Топ-10 «лучше Suvvy при равных усилиях»

1. AOP-политики на русском вместо мега-промпта с #секциями
2. Approval-инбокс в TG с risk-классификацией
3. Отчёт владельцу о ROI в рублях/бронях
4. Эскалация при низкой уверенности с полным контекстом
5. Диалоговый онбординг вместо мусорной генерации
6. Бронь столиков как действие с auto-confirm
7. Resolution rate как главная честная метрика
8. «Какой источник сработал» + объяснение решений
9. Память гостя («как обычно»)
10. Прайсинг «за результат» + партнёрская наценка в схеме биллинга

## УТП

Простота для владельца без тех-бэкграунда — оба СНГ-конкурента (Suvvy, Wikibot) строят интерфейс для настройщика-технаря (промпты, JSON, формы). Мы строим для владельца: всё рождается из диалога и работы системы.
