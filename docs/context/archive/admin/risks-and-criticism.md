# Критика и риски (red team + симуляции)

Сводка трёх стресс-тестов: red team (кофаундер + инвестор), 8 враждебных клиентов-скептиков, инвест-комитет.

## Главные риски и статусы

| Риск | Источник | Статус | Как нивелируется |
|---|---|---|---|
| Гости пишут в мессенджеры заведения, не в веб-чат | Скептики | решено | TG-бот в MVP, VK/MAX/Avito позже |
| Холодный джун на выжженном рынке (негатив к ботам 68,8%) | Скептики | решено | Фаундер продаёт первые 20 клиентов; джун — встречи и кастдев |
| «Часы» ≠ KPI рынка | Скептики | решено | Отчёт деньгами (брони × чек) |
| ЛПР-разрыв в сетях | Скептики | решено | ICP сужен до независимых владельцев-ЛПР |
| Part-time фаундер = скорость ниже скорости копирования | Все | принятый риск | Уход при MRR ≥ расходы + подушка; скоуп-фриз |
| Финмодель: честная база −160 тыс ₽ за 24 мес | Red team | принятый риск | Рычаги: конверсия 35%, чек 20→35 тыс, контент ×2 |
| Retention общепита недоказан (заведения мрут 20–30%/год) | Инвесторы | проверяется | Кастдев + пилоты ≥4 мес |
| Команда на долях развалится до пилотов | Red team | управляем | Вестинг, клифф, demo-day, «красная неделя» |
| Яндекс добавит нативные ИИ-ответы (≤12 мес) | Конкуренты | мониторим | Ценность смещена в брони+отчёты |
| Недоверие: «вы кто такие», данные, «уже есть бот» | Скептики | решено | НДА + схема данных, режим стажёра, разбор диалогов клиента |
| Виджет «молчит» — сайт не открывают | Продукт | решено | QR на столы/Карты + TG главным каналом |
| Галлюцинация по аллергенам | Продукт | решено | Только точное совпадение, иначе approval |
| Approval fatigue | UX | решено | Батчи, автоправила после 3 подтверждений, дайджест, цель ≤5 карточек/день |
| Фонды не дадут денег (юрисдикция, размер исхода) | Инвесторы | принято | Только ангелы/bootstrap |

## Вердикты стресс-тестов

Кофаундер: «Идея нормальная, конфигурация — хобби с финмоделью» → исправлено (команда, скоуп-фриз, фаундер продаёт). Инвест-комитет дал три «нет», но их чек-лист совпадает с планом ниже. Скептики-клиенты: часть рестораторов не купят никогда — это нормально, ICP сужен до тех, кто купит.

## Чек-лист де-рискинга на 6 месяцев (= план бизнеса)

- MVP-1 у 3–5 пилотов, из них ≥3 не из знакомых
- ≥3 платящих ≥15 тыс ₽, прошла оплата 2–3-го месяца
- Churn ≤3%/мес на горизонте 4+ мес; ≥60% диалогов без эскалации
- Один воспроизводимый канал с посчитанным CAC (конверсия ≥10%)
- Кейс с цифрами клиента «+N броней = ₽» (подписанный)
- Публичная дата фултайма фаундера (MRR 120–150 тыс)
- Policy-датасет ≥1000 решений владельцев (первый кирпич moat)

## Kill-критерии

- Мес 2: 20 интервью, ≥5 «возьму пилот за деньги» — иначе пивот сегмента.
- Мес 4: ≥2 предоплаченных пилота — иначе пересмотр оффера.
- Мес 8: ≥3 платящих, ≥1 прожил 3 мес — иначе разговор о гибриде с агентством.
- Мес 12: MRR ≥100 тыс и рост ≥15%/мес — иначе честный разбор с командой до клиффа.
