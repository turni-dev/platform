# Вертикали и кейсы: карта расширения

Общепит выбран гипотезой №1 только по доступу к контактам (не по красоте рынка), консалтинг — №2. Документ — карта всех кандидатов вертикалей для осознанного расширения; продукт один: входящие обращения → типовое сам / рисковое через approval → отчёт.

**Оценка (шкала 1–5) по потоку, чеку, боли, риску ошибки (ниже лучше), конкуренции (ниже лучше):** общепит (выбран — доступ + свободная ниша); салоны красоты/барбершопы (боль доказана, но занята Suvvy — входить через «контроль»); стоматологии/медцентры (высокий чек и боль от 152-ФЗ, но риск высок — входить позже); автосервисы/детейлинг/шиномонтаж (недооценённая ниша, мало конкурентов, сезонные пики — «идеально для агента»); онлайн-школы GetCourse (привычны к ботам, платят за инструменты, но интеграция GetCourse есть и у Suvvy); селлеры WB/Ozon (огромный сегмент, но чувствительны к цене); фитнес-клубы (похоже на салоны, меньше конкуренции); недвижимость (дорогой лид, сценарий «не упусти лид ночью»); отели/глэмпинги (сезонность, высокий чек брони, депозиты через approval); малый консалтинг (№2 по доступу, поток мал — ценность в цене лида); ремонт/стройка (фрагментированный, но голодный сегмент); детские центры (низкий чек, скорее P2).

**Выводы:** единый паттерн «запись/бронь + FAQ + жалобы через approval + отзывы» покрывает 80% вертикалей — продукт строится вокруг паттерна, вертикаль = шаблон онбординга + словарь + дефолтные политики. Кандидаты на вертикаль №2 после общепита (если консалтинг не подтвердится): автосервисы или онлайн-школы. Стоматологии/медцентры — самый высокий потенциал, но входить позже (нужен зрелый policy-слой и кейсы). Правило выбора: доступ к 3+ тёплым контактам важнее красоты рынка. Единый кастдев-скрипт для всех вертикалей: «как сейчас отвечаете на обращения → что пробовали → почему отключили → сколько стоит упущенный клиент».

Кейсы-иллюстрации для лендинга: банкет в общепите через approval; ночной расчёт стоимости в автосервисе; возврат за курс в онлайн-школе через approval; ответ на негативный отзыв WB через approval; квалификация лида риелтора с Авито ночью.
