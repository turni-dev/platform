# Экраны и состояния: handoff для дизайна

Рабочий документ Business Analyst (12.06.2026) для Figma-прототипа.

**Карта экранов:** O1 Онбординг-чат, D1 Дашборд, A1 Approval-инбокс, A2 Карточка approval, C1 Список диалогов, C2 Просмотр диалога, K1 База знаний, R1 Отчёт, S1 Настройки, G1 Гостевой веб-чат (публичный, по QR). Регистрация ведёт через O1 (с aha-тестом) в D1, откуда таб-бар/сайдбар ведёт ко всем разделам; TG-пуш открывает A2 напрямую по deep link; G1 изолирован от остального кабинета.

**Ключевые спецификации:** O1 — агент-интервьюер пишет первым, empty-состояния не существует, финал — аha-тест «напишите как гость». D1 — цель «всё ли в порядке за 5 секунд», счётчик ожидающих решений, таймлайн с обоснованиями. A1 — mobile-first, карточка с сутью в одну строку/черновиком/таймером/свайпами, батчи однотипных, эмпти-стейт «агент справляется сам — это хорошо», правило предложения авто-правила после 3 однотипных одобрений, undo-тост. A2 — раскрытая карточка с редактируемым черновиком и объяснением причины, обработка состояния «уже решено с другого устройства». C2 — три визуально разных автора реплик (гость/агент/владелец), «вмешаться»/«вернуть агенту», «добавить ответ в базу». K1 — карточки тем с частотой использования, блок «вопросы без ответа». R1 — герой-цифра сэкономленных часов, кликабельная к реальным диалогам. G1 — без брендинга платформы, честные сообщения про ожидание approve и тихие часы.

**Сквозные паттерны:** тосты с undo (approve/reject, удаление знания, отправленные сообщения — 30 сек), подтверждение опасных действий формулировкой последствия языком кухни («Гость получит: …») вместо «Вы уверены?», единый индикатор «агент думает», единый раскрываемый компонент-объяснение (причина + источник) во всех местах, где агент принял решение.

**Открытые вопросы дизайнеру (не решены на момент архивации):** защита от случайного свайпа в инбоксе, баланс срочности/тревожности таймера ожидания, форма предложения авто-правила, глубина раскрытия компонента-объяснения по умолчанию, что видит гость при вмешательстве владельца, режим массового одобрения стопок 20+, настраиваемость формулировок для гостя.
