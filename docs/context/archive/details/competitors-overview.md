# Конкуренты: обзор игроков и цен (июнь 2026)

**Глобальные игроки:** Lindy (личный ассистент, 4000+ интеграций), Relevance AI (единственный SMB-игрок с approval gates, но сложный setup), Sintra (12 «сотрудников» для микробизнеса, $16-39/мес, 60k+ клиентов), Intercom Fin (оплата за результат), Tidio Lyro (SMB e-commerce), Microsoft Agent 365 (enterprise governance), Sierra/Decagon/Cresta (дорогой enterprise CX с supervisory agents и AOP-политиками), Slang/Hostie/Loman (voice-агенты для ресторанов США, $199+/мес, 81% звонков без персонала).

**СНГ:** Suvvy (от 1000 ₽/мес, 25+ каналов, 300+ партнёров-интеграторов — основной конкурент, но без общепита); Wikibot (от 990 ₽/1000 ответов, поддержка); Aimylogic (прошлое поколение no-code); GigaChat Enterprise (не SMB); 3iTech/Nikta/NeuroAgents и подобные (заказная разработка, 250-500 тыс ₽ разово, сервисная модель).

**Ключевые выводы:** ниша «мессенджер-агент для общепита под контролем» свободна — Suvvy силён в записи на услуги (YCLIENTS/Altegio-ниши), западные ресторанные игроки voice-first и не в СНГ. Approval/supervision в SMB-сегменте не предлагает никто — это паттерн из enterprise (Sierra/Decagon/Cresta), перенесённый в SMB-цену. Рынок структурно двухэтажный: дешёвый self-serve (990-10 тыс ₽) или дорогое внедрение (250 тыс+ ₽) — продукт целится в промежуток за 15-25 тыс ₽/мес. Для СНГ обязательны: Telegram-каналы, хранение данных в РФ (152-ФЗ), рубли; WhatsApp исключён из-за блокировки.
