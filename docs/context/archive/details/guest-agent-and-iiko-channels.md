# Клиентские каналы (агент-гость) и интеграция iiko

Исследование 12.06.2026, вызванное симуляцией: гости общепита пишут в мессенджеры/соцсети заведения, а не в веб-чат, что заставило пересмотреть приоритет каналов.

**Данные по каналам (дек 2025):** Telegram лидирует (74,3 млн/день), WhatsApp близко (69,8 млн/день), но блокируется в РФ; MAX растёт (42 млн, предустановки, госвектор); VK силён в регионах (~93,8 млн активных). Вывод: TG-бот заведения возвращён в MVP (был отложен в P1, симуляция это отменила); веб-чат остаётся как fallback/демо, но больше не главный канал. VK и Avito Messenger — P1 по сегменту; телефония признана честным гэпом (звонки — большой канал общепита), перехват пропущенных звонков → текст — кандидат на MVP-3.

**Архитектурное следствие:** Channel Adapter спроектирован как plugin-слой — добавление канала = новый адаптер без изменения ядра. MVP-1 стартует с двух адаптеров (TG + веб).

**iiko подробно:** iikoCloud API, токен живёт 1 час, лицензия Cloud API обычно активируется через дилера (трение в онбординге — шаг «попросите дилера включить API»). Релевантные возможности: выгрузка меню с ценами → автонаполнение RAG; стоп-листы с вебхуком обновления — решает найденную в симуляции проблему «бот врёт про наличие блюда»; резервы/банкеты (GetReserves, ReserveUpdate, BindReserveToOrder с предоплатой) — прямое попадание в сценарий «банкеты через approval». Риски: зависимость от дилерской лицензии, расхождения ID столов между API-версиями, нужен тестовый стенд. Альтернатива для малых заведений — Restoplace (публичный REST, есть синк с iiko).

**План интеграции iiko:** MVP-2 — read-only меню + стоп-лист с вебхуком в RAG; MVP-3 — reserves read (честные ответы про занятость); MVP-3+ — reserves write через approval, предоплата банкета откладывается как действие высшего риск-класса.

**YCLIENTS** (для будущих вертикалей услуг) — платформа записи, не канал; интеграция через маркетплейс с OAuth и активацией в течение часа. Для общепита не нужна; для салонов — территория Suvvy, куда решено не идти; может пригодиться при расширении на автосервисы/частные клиники. Статус: отложено, задокументировано.
