# Узкие места: симуляция предвзятых клиентов и инвест-комитета

Симуляция 12.06.2026 через 8 враждебных персонажей-клиентов и 3 инвесторов, подкреплённая реальными жалобами рынка.

**Блокеры:**
1. Веб-чат по QR как канал гостя не совпадает с реальностью — гости общепита пишут в соцсети/мессенджеры заведения (ВК, TG, бывший WA), на сайт почти не заходят; решение — проверить в кастдеве «куда вам писали гости вчера», вероятный фикс — TG/VK заведения раньше плана, QR как дополнение.
2. Холодная продажа джуном на выжженном рынке ботов (68,8% негатива к ботам по Markswebb) обречена — первые 20 продаж должен вести фаундер лично, джун только назначает встречи и ведёт кастдев.
3. ЛПР-разрыв в сетях: демо смотрит управляющая, платит собственник, для которого это «игрушка» — нужен материал в деньгах для собственника, пилот только с его подписью.
4. Ценность в «часах» не совпадает с KPI рынка — покупатели считают в выручке/конверсиях/фудкосте; отчёт нужно пересобрать так, чтобы «спасено N броней × средний чек = ₽» было главным числом.
5. Инвест-кейс отклонён всеми тремя симулированными инвесторами (part-time фаундер, ноль клиентов, нет канала) — рекомендация целиться в ангелов/bootstrap, не тратить время на фонды.

**Сильное трение (не блокер, но режет воронку):** цена 15-25 тыс при марже общепита 5-10% ощутима для малых кафе; агент без актуальных данных о наличии опасен (подтверждает приоритет книги броней и iiko read); опасения конфиденциальности (переписка через сервер + зарубежная LLM) требуют НДА и схемы данных до пилота; нужен роутинг approval-карточек по ролям для команд с несколькими сотрудниками; сезонность тарифа для сезонного бизнеса (глэмпинги); восприятие продукта как «дополнительной работы владельца» требует честной кривой обучения.

**Уточнённый ICP:** владелец 1-2 «инстаграмных» заведений, 28-40 лет, город-миллионник, средний чек 1500₽+, сам ЛПР, живёт в Telegram, есть поток обращений, который реально бесит; покупает по рекомендации от фаундера, не у холодного джуна.

**Чек-лист де-рискинга на 6 месяцев:** MVP-1 у 3-5 пилотов (≥3 незнакомых), ≥3 платящих по чеку ≥15 тыс с retention 2-3 месяца, churn ≤3%/мес, один воспроизводимый канал с посчитанным CAC, кейс с цифрами клиента, публичная дата перехода фаундера в фултайм привязанная к MRR 120-150 тыс, датасет approved/edited-ответов ≥1000 как первый кирпич moat.

**Затронутые решения, вынесенные на эскалацию:** пересмотр канала гостя MVP в пользу TG/VK; смена роли продажника с «продаёт» на «назначает встречи»; отчёт с деньгами как главным числом; добавление НДА, схемы данных и сезонной паузы подписки в оффер.
