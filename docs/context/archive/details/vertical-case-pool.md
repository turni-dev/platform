# Вертикали: расширенный пул кейсов

Продукт один и тот же (агент + approval + отчёт), меняется только упаковка и сценарии по вертикали. Оценка кандидатов по критериям: поток обращений, готовность платить 15–25 тыс ₽, риск ошибки агента (ниже лучше на старте), доступ к тёплым контактам, занятость ниши конкурентами.

**Фаворит №1 — общепит** (кафе, доставка): высокий поток, есть доступ у команды, ниша свободна от главного конкурента (Suvvy). **Фаворит №2 — малый консалтинг**: низкий поток, но высокий чек и высокий риск ошибки делает approval особенно ценным; тоже есть доступ.

Прочие кандидаты с заметками: продавцы WB/Ozon (тёмная лошадка — огромный рынок, простой сценарий «ответы на отзывы», но Suvvy уже там); онлайн-школы GetCourse (сильный кандидат — кураторы перегружены, привычны к ботам); автосервисы/детейлинг (хороший — запись + расчёт стоимости, низкая конкуренция); салоны красоты/барбершопы (скип на старте — высокая конкуренция, это домен Suvvy/Altegio); медклиники/стоматологии (богатый рынок, но высокий риск из-за медицины и ПДн, войти позже с комплаенсом); недвижимость, туризм/глэмпинги (близнец общепита — брони+сезонность), ивент, цветы/подарки, ремонт/клининг — все с разной комбинацией потока/чека/риска. B2C личный ассистент — отдельный трек, не источник выручки.

**Выводы:** продукт проектируется вертикально-независимым (профиль бизнеса + сценарии + политики = конфигурация), вертикальна только упаковка. В кастдев стоит добавить по 2–3 интервью из WB/Ozon, онлайн-школ и глэмпингов для дешёвой проверки боли. Восемь общих сценариев (FAQ из базы знаний, приём заявки/брони, квалификация лида, эскалация жалобы через approval, ночные обращения, анти-no-show напоминания, ответ на отзыв через approval, недельный отчёт) покрывают все 14 рассмотренных вертикалей — подтверждение универсальности ядра. Правило расширения: новая вертикаль = новый шаблон онбординга + 1-2 интеграции, не новый продукт; берём следующую, когда в текущей ≥5 платящих.
