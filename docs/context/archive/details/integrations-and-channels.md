# Интеграции и каналы: приоритизированный список

**Каналы коммуникации:** Telegram-бот и веб-чат/виджет — MVP (гости живут в TG, риск блокировок минимален; веб-чат — под полным контролем без модерации). Telegram Business, VK, Avito Messenger, Email — P1-P2. WhatsApp — де-факто скип: с окт. 2025 частично блокируется в РФ, к концу 2026 ожидается полная блокировка, серые шлюзы рискованны — строить продукт на этом нельзя. Яндекс.Карты/2ГИС отзывы — публичного API нет, обход: мониторинг + черновик ответа владельцу через approval. Instagram — скип (Meta признана экстремистской и запрещена в РФ). Телефония/голос — скип до 2027 (дорого).

**Вертикальные интеграции общепита:** своя книга броней в Postgres — MVP (без внешних интеграций). iiko (iikoCloud API) — P1, начиная с read-only (меню, стоп-лист → RAG), запись брони вторым шагом; лицензия требует дилера. Restoplace — дешёвая альтернатива для малых кафе. r_keeper — скип до появления 3+ платящих клиентов на нём.

**CRM/бизнес-инструменты:** Google Sheets — MVP («бэкенд для бедных»). Google Calendar и amoCRM — P1 (ядро консалтинг-трека); Google OAuth-верификация занимает 2-4 недели. Битрикс24 — P2.

**B2C-трек:** Todoist, Gmail/Google Calendar (общий OAuth-коннектор с B2B), Obsidian через markdown-vault. Поле видимости owner|team в модели данных решает кейс «скрытые поля задач» без отдельной интеграции. Кейс здоровья (Вера) — нереалистичен в TG-стеке: нужные SDK (Samsung Health, Mi Fitness) закрыты/деприкейчены для серверного доступа — отложено до мобильного клиента.

**Итоговая корзина MVP (6):** TG-бот гостя, веб-чат/виджет, approval-инбокс в кабинете + TG-нотификатор, своя книга броней, Google Sheets, мониторинг отзывов Я.Карт.

**Правило добавления интеграции:** берём только если просят ≥3 платящих клиента (или 1 якорный с ≥20% MRR), публичный API без партнёрской сертификации, и объём работ ≤2 недель одного разработчика — иначе ручной обход через approval-карточку.
