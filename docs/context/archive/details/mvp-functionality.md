# Функционал MVP: «минимум лучше Suvvy» + лучшие западные паттерны

Принятый на 12.06 «минимальный продаваемый срез»: 6 сценариев, автономность тумблером, биллинг вручную, канал гостя — веб-чат+QR с TG-нотификатором владельцу.

**Заимствования из западных решений:** Intercom Fin (pricing за результат, Procedures как многошаговые инструкции, resolution rate 50-70% как бенчмарк), Tidio Lyro (единый inbox человек+ИИ, быстрое обучение на FAQ), Chatbase (бенчмарк time-to-live 30-60 мин, антипаттерн — слабый RAG и нет handoff), Sierra (supervisory agents — второй агент-надзиратель steering'ует основного), Decagon (AOP — политика на естественном языке, компилируемая в аудитопригодные правила; Watchtower real-time QA), Cresta (HITL-супервизия как отдельный продукт), Slang/Hostie/Loman (ресторанная вертикаль уже валидирована в США, но voice-first — в РФ гость пишет, а не звонит, поэтому ниша «мессенджер-first ресторанный агент» свободна). Ключевой вывод: approval/supervision в SMB-сегменте нет ни у кого — только в enterprise за сотни тысяч $; перенос этого паттерна в SMB-цену и есть продукт.

**Планка «лучше Suvvy»:** диалоговый онбординг вместо генерации промпта, гарантированный быстрый первый ответ, risk-классификатор с approval-карточками вместо простого call_manager, AOP-паттерн видимых редактируемых правил вместо простыни промпта, таймлайн с источниками вместо технических логов, дешёвый supervisor-LLM для рискованных ответов, единый чат с handoff вместо «агент молчит после перехвата».

**P0 (MVP, без этого не продаём):** диалоговый онбординг, веб-чат/виджет (TG-бот — P1), RAG с источником в каждом ответе, risk-классификатор + AOP-light политики с default deny, approval-инбокс с тихими часами и SLA-эскалацией, три уровня автономности (стажёр→помощник→администратор), таймлайн + недельный отчёт, единый чат-инбокс с draft-режимом при вмешательстве, fallback-модель через OpenRouter, каркас биллинга.

**P1 (после 3 пилотов):** Telegram-канал с approval-карточками, книга броней, WhatsApp/VK/Avito, supervisor-LLM на всех ответах, маскирование ПДн, PDF-отчёт, мульти-точка, аудит политики. **P2:** конструктор ролей вне общепита, команды агентов, маркетплейс-приложения, white-label, голос. **Анти-scope:** рассылки, автономные платежи, конструктор промптов «агент может всё», 20 каналов сразу, своя LLM.

**Бенчмарки успеха:** resolution ≥60% к 3 месяцу, time-to-live ≤1 день, доля правок в approval <30% к месяцу 2, CSAT гостей ≥90%.
