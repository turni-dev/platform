# Нефункциональные требования и архитектура фронтов

## Нефункциональные требования (НФТ)

| Категория | Требование | Проверка |
|---|---|---|
| Производительность | Ответ гостю p95 ≤10 с (бюджет по этапам) · TTFB кабинета <300 мс · виджет ≤70 KB gzip, TTI <1.5 с на 3G · лендинг Lighthouse ≥90 | k6 + CI bundle-size гейт + Lighthouse CI |
| Доступность сервиса | 99.5% (соло-он-колл честно) · RTO 30 мин, RPO 0 (данные) | UptimeRobot, runbook-учения квартально |
| Надёжность | Ни одно входящее не теряется (Postgres-inbox при падении Redis) · идемпотентность вебхуков и мутаций · undo 30 с | e2e-тесты отказов |
| Безопасность | Обязательный минимум: OWASP Top 10:2025 + OWASP Top 10 for LLM Apps 2025 · Топ-5 AppSec до пилота (см. specialist-review.md) · 152-ФЗ: данные в РФ, согласие в виджете, экспорт/удаление тенанта | OWASP-крослист в DoD + чек-лист перед пилотом |
| Качество ИИ | FN риска ≤2% (CI-гейт) · faithfulness ≥95% · 0 инцидентов аллергены/деньги | eval-сьют |
| Масштабируемость | 1 VPS = год-1 (×3 запас) · партиции events · порты/адаптеры для замены вендоров | нагрузочный тест |
| Сопровождаемость | strict TS везде, `any` запрещён eslint'ом · zod на всех границах (env, API, события, очереди) · coverage domain/policy ≥80% · ADR на каждое архитектурное решение (папка docs/adr) | CI |
| Совместимость | Кабинет: последние 2 версии Chrome/Safari/Firefox + мобильные · Виджет: ES2019, без тяжёлых полифиллов, работает в iframe любого сайта | browserslist + smoke на устройствах |
| Юзабилити | Язык кухни, не IT · mobile-first инбокс · «каждый экран — ценность за 5 сек» | юзер-тесты прототипа |
| Правовое | Оферта, политика ПДн, согласие в виджете, журнал согласий · агент раскрывает, что он ИИ | юрист разово |

## Локализация и интернационализация

- UI MVP — только русский. i18n-каркас закладывается сразу: все строки через словарь (next-intl messages), хардкод строк в JSX запрещён линтером. Цена сейчас ≈0, ретрофит потом — недели. Второй язык (en) — при выходе за СНГ, не раньше.
- Агент отвечает на языке гостя — это LLM-свойство, не i18n (гость получает ответ на своём языке из коробки; политики проверяются на смысле, не на языке).
- Форматирование: `Intl.*` (даты, числа, ₽), TZ per location (`Europe/Moscow` дефолт).
- Системные фразы гостю («уточню и вернусь», тихие часы) — настраиваемые шаблоны тенанта (хранятся в settings, не в словаре приложения) — это и кастомизация, и «локализация» голоса заведения.

## Типизация (закон)

`strict: true` + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` · ts-reset · eslint: no-explicit-any, no-floating-promises · единственный источник типов — `libs/contracts` (Zod-схемы → `z.infer`), Drizzle-типы — из схемы БД · виджет и фронт импортируют только contracts · runtime-валидация на каждой границе (HTTP, WS, очереди, env через zod-env, LLM structured output).

## CMS: Strapi — в строгих рамках

**Решение:** Strapi v5 как `apps/cms` (отдельный compose-сервис + отдельная база/схема, домен cms.turni.ru за basic-auth+IP). Контент ведут продажник/маркетолог, не разработчики — markdown-in-repo для них не работает.

**Рамки (нарушение = архитектурная ошибка):**
1. Только маркетинг-контент: блоки лендинга, блог/кейсы, FAQ, публичные доки, вакансии. Ни одной бизнес-сущности (тенанты, агенты, политики — никогда).
2. Лендинг тянет контент на build (SSG) + ISR-revalidate по вебхуку Strapi. Падение CMS не валит ничего, кроме редактирования контента.
3. Доступ через `CmsPort` (см. ports-and-adapters.md) — если Strapi надоест, меняем на Payload/markdown без переписывания лендинга.

## Разделение фронтов

```
libs/ui — дизайн-токены (CSS vars), примитивы, иконки, тема
  → apps/landing: Next.js SSG+ISR · turni.ru · контент из Strapi · SEO · SCSS
  → apps/web: кабинет · app.turni.ru · shadcn в ui/ + SCSS-модули
  → packages/widget: ≤70KB · cdn.turni.ru · Preact/vanilla, Shadow DOM (только токены, не компоненты)
apps/cms: Strapi · cms.turni.ru (build-time связь с landing)
```

- Лендинг — отдельное приложение: другой ритм релизов (контент ежедневно, кабинет спринтами), другие требования (SEO/скорость vs интерактивность), независимый деплой. Никакого shadcn на лендинге — чистый SCSS.
- `libs/ui` разделяет токены (цвета, типографика, радиусы, отступы — CSS-переменные, источник для дизайнера в Figma) и примитивы (Button, Input, Badge — используют токены). Кабинет добавляет shadcn-слой поверх тех же токенов. Виджет берёт только токены (бандл!), компоненты свои микроскопические.
- Домены: turni.ru (лендинг) · app.turni.ru (кабинет) · cdn.turni.ru (widget.js loader) · cms.turni.ru (закрыт) · api.turni.ru.

## Observability-стандарт

Replay <5 мин: любой упавший/спорный диалог воспроизводится из аудита+трейса (`correlation_id`, events, snapshot вердикта) за <5 минут. Иначе — не production-ready. Это обязательная НФТ (прод-готовность держится на eval + observability + governance, не на модели). Подробнее про Production Playbook — в tech-decisions.md.
