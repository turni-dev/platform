# Дизайн-контекст

Всё, что нужно для работы над дизайном (UX/UI/визуал) продукта Turni, собрано здесь отдельно от инженерной документации в `docs/context/` и `docs/superpowers/`, чтобы это можно было целиком скормить как контекст в дизайн-инструмент.

## Файлы здесь

- [`design-ux.md`](./design-ux.md) — сводный источник: иллюстрации корп-сайта (лист промптов), тексты и композиция блоков сайта, фидбэк/кредиты/интеграции (build-ready модель данных), 15-экранная спека прототипа MVP-1, системные/служебные экраны, UX-принципы, дизайн-концепция, дизайн-система (токены, компоненты), референсы. **Главный документ** — начинайте отсюда.
- [`screens-and-states.md`](./screens-and-states.md) — handoff-заметка для Figma-прототипа: карта экранов, ключевые спецификации по экрану, сквозные паттерны, открытые вопросы дизайнеру.
- [`ux-flows-and-patterns.md`](./ux-flows-and-patterns.md) — принципы и три ключевых флоу (диалоговый онбординг и др.) от UX-исследователя.
- [`ui-tokens.md`](./ui-tokens.md) — снимок CSS-токенов для контекста (справочно; редактировать код, не этот файл — источник истины `packages/ui/src/tokens.scss`).

## Статус курса продукта (важно)

MVP-1 переориентирован на **персональные автоматизации** для бизнеса (решение 16.08.2026), не на гостевой поток общепита. Экраны кабинета владельца (дашборд, approval-инбокс, диалоги, база знаний, настройки) остаются актуальными. Общепитовские гостевые сценарии (G1, 13 сценариев в `design-ux.md` §4.4) — вторичный/архивный набор, иллюстрирующий UX-паттерны (approval, ExplainWhy, undo), не текущий продуктовый скоуп. Экраны подключений/интеграций и автоматизаций под новый курс в источниках ещё не спроектированы — это открытая работа.
