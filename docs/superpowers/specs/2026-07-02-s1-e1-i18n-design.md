# S1 E1 Web I18n Design

## Goal

Create the minimal `apps/web` Next.js App Router shell with Russian-only
`next-intl` messages and a lint gate against user-visible JSX literals.

## Acceptance Criteria

- Locale is fixed to `ru` without locale URL routing for MVP-1.
- Server and client components receive the same checked message catalog.
- Visible JSX text, `title`, `alt`, `placeholder`, and `aria-label` literals are
  rejected by ESLint in `apps/web`.
- No Tailwind is introduced; the shell uses a scoped SCSS/CSS module.
- Test, lint, typecheck, and production build are Nx targets.
